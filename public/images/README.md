# Images

## Headshot

Place a professional headshot of Anubhav Mittal at:

    public/images/anubhav.jpg

The About page uses this exact path. Until the file is present, the UI
renders an elegant navy gradient card with an "AM" monogram so the page
still looks complete.

### Recommended specs

- Aspect ratio: **4:5 (portrait)** — the frame is `aspect-[4/5]`
- Minimum size: **800 × 1000 px** (1600 × 2000 px ideal for retina)
- Color: full-color; lightly retouched, neutral background or
  professional environment
- Format: JPG (preferred), PNG also fine
