# Organization Logos

Drop PNG (or SVG renamed to .png) logo files into this folder using the
filenames below. The site references each logo by an exact path; if a file
is missing or fails to load, the UI renders a polished navy monogram block
in its place — so the page always looks finished, with or without these
assets.

## Recommended sources

- **ADM, Kellanova/Kellogg, Unilever**: each company's official media /
  brand kit page on its corporate site.
- **Booz & Company**: archived brand kit (the firm has since been
  reorganized into Strategy&); Wikimedia Commons hosts the historical
  wordmark.
- **Harvard Business School, IIT Kanpur**: the institutions' official
  identity / branding pages.
- **CFA Institute, IMA (CMA)**: each body's media-kit page.

## Sizing guidance

Square PNGs at 256×256 or 512×512 work best. The component renders the
image with `object-contain` inside a 64–80px rounded square, so logos with
generous internal padding tend to look cleanest.
